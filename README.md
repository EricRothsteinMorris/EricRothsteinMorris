# Eric Rothstein-Morris

I am a computer scientist with a Ph.D. in Information Systems.
My research applied formal methods to security: attacker models,
compiler hardening, and cyber-physical systems. Since 2022, I have
worked in industry, most recently running Elastic SIEM clusters
for German healthcare institutions.

## Now
- Learning Lean 4, both as a programming language and as a
  theorem prover.
- Goal: tools that make formally verified code the expected output
  of AI-assisted software development.

## Selected projects
- **dh-mitm**: Lean 4 proof that the original Diffie–Hellman
  key exchange is vulnerable to a man-in-the-middle attack.
  Work in progress, not yet public.
